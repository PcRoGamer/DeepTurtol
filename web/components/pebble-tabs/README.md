# Pebble Tabs Component

Organic 3D stone and quartz pebble tab bar component for conversation switching in DeepTutor.

## Features
- Irregular stone shapes with 3D highlights and volumetric SVG grain textures.
- Automatic subject-based grouping of conversation sessions.
- Staggered cascading dropdown list for individual conversation pebbles.
- White quartz active tab lighting.
- Responsive expandable and collapsible row controls.
